# employee-sql-cte-window-recursive-queries
PostgreSQL practice project covering CTEs, aggregations, window functions, salary analysis, employee hierarchies, and recursive CTEs.
Employee SQL Analysis – CTEs, Window Functions & Recursive Queries

📌 Project Overview

This project contains SQL exercises using an Employees table to practice advanced SQL concepts commonly used in Data Analyst roles.

The project focuses on Common Table Expressions (CTEs), aggregations, window functions, salary analysis, employee hierarchy analysis, and recursive CTEs.
Analyzed:

- Employees earning above department average
- Highest-paid employee in each department
- Lowest-paid employee in each department
- Salary difference from department average
- Employees earning above company average
- Highest-paid employee in the company
